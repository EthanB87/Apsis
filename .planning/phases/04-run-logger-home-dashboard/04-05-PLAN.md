    - After write: recomputeLoadDaily is called; the new workoutId is returned for navigation.
  </behavior>

    - packages/engine/src/session.ts (sessionHSSDetailed input { enduranceSegments: [...] } -> hss)
    - packages/db/src/schema.ts (workout: id/localDate/type/note/hss/finishedAt; endurance_segment: activityType/distanceM/durationS/avgHr/intensityFactor/stressScore)
    - apps/mobile/lib/recomputeLoadDaily.ts + apps/mobile/lib/localDate.ts
    - .planning/phases/04-run-logger-home-dashboard/04-RESEARCH.md (Pattern 3 IF resolution; Pitfall 6 erg pace domain)
  </read_first>
  <action>
    Create apps/mobile/lib/runEntry.ts exporting saveRun(database, input: RunEntryInput) returning the
    new workoutId. RunEntryInput = { activityType: 'run'|'erg'|'conditioning', distanceM?: number,
    durationS: number, avgHr?: number, note?: string, localDate: string }. Steps: (1) read the profile
    thresholds (thresholdHr, thresholdPaceSecPerKm) via a profile query; (2) compute paceSecPerKm =
    distanceM>0 ? durationS/(distanceM/1000) : undefined; (3) call resolveIF with avgHR + thresholdHR
    always, and paceSecPerKm + thresholdPaceSecPerKm ONLY when activityType === 'run' (Pitfall 6 -
    ERG/CONDITIONING never pass a pace); (4) enduranceStressDetailed({ durationS, intensityFactor }) for
    the stress; (5) insert workout { id: randomUUID(), localDate, type: 'endurance', note: note ?? null,
    finishedAt: new Date() } (endurance sessions are complete on save - no open-session lifecycle);
    (6) insert endurance_segment { id: randomUUID(), workoutId, activityType, distanceM: distanceM ?? null,
    durationS, avgHr: avgHr ?? null, intensityFactor, stressScore }; (7) sessionHSSDetailed({
    enduranceSegments: [{ durationS, intensityFactor }] }) and UPDATE workout.hss; (8) await
    recomputeLoadDaily(database); (9) return workoutId. Parameterized drizzle builders only; console.error
    + re-throw on failure (caller shows a generic message). Note momentary erg absence of HR is valid
    (neutral IF), not an error.
  </action>
