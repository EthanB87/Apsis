<objective>
Add the unit chip row to every food-quantity entry point and make the FoodConfirmSheet keyboard-safe, so a
user can type a quantity in oz/lb (or tsp/tbsp/serving when available) and watch macros update without the
keyboard hiding anything.

grams were enterable. This plan wires the tested 09-02 conversion logic and the 09-04 Done bar into the UI.

keyboard-safe confirm sheet (D-12); the Done bar on all four inputs (D-11/D-13); last-used-unit default (D-09).
