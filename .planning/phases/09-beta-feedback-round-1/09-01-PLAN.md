<assumption_delta_decision>
Noun now primary: the **per-domain unit preference** (lifts / bodyweight / runs).
Decision: **promote** — the three new columns become the primary display source of truth; the legacy
single `user_profile.units` column is demoted to (a) the D-04 backfill source and (b) a rollback anchor,
and is no longer read for display once the 09-05 sweep completes. This is not add-alongside: no display
call site keeps reading the old single value after the sweep.
Rationale: a still-read old column plus three new columns would drift; a single promoted representation
with the old value retained only as migration/rollback data keeps one source of truth per display.
Suggested invariant (enforced by 09-05 acceptance): every unit-formatting call site resolves through
exactly one of the three buckets, never `profile.units`.
</assumption_delta_decision>
