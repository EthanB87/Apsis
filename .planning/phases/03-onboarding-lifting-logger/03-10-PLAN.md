<objective>
Close the one remaining Phase 03 UAT gap (Test 9, severity minor): the set-logging UI "is a little broken and spaced weird" because SetRow's intrinsic single-line width (~690px) is roughly double what fits inside an ExerciseCard on any iPhone, and `styles.row` wraps on overflow so every set row silently folds into 2-3 ragged lines.

The fix now follows DESIGN-SYSTEM.md (repo root, commit d8df06a) — the user-provided authoritative design contract that supersedes 03-UI-SPEC.md where they conflict. Contract §5: "Steppers for LOAD KG / REPS / RPE: big mono value, +/- buttons, 44px targets." So the −/+ steppers STAY (the user has pre-answered that decision), and the single line becomes geometrically feasible because (a) RPE changes from five 44px pills (~236px) to a stepper group (~74px), (b) all stepper/checkmark VISUALS shrink to 24-32px with hitSlop supplying the 44pt hit target (the "44px targets" reading, matching SetRow.tsx's own header comment and the UI-SPEC Spacing-Scale exception), and (c) inline unit labels move to a mono column-header row.

Recomputed width budget (values are mono-glyph estimates, ±a few pt):
- Available on the narrowest supported iPhone (375pt): 375 − 2×16 card margin (Spacing.lg, contract scale) − 2×12 row padding (Spacing.md=12, new token from Plan 03-11) = ~319pt.
- Primary-row content: W chip 24 + load group ~92 (24 stepper + 40 mono value + 24 stepper + inner gaps) + reps group ~76 (24+24+24+gaps) + RPE group ~74 (24+22+24+gaps) + checkmark 32 + 4 top-level gaps ×4 = ~314pt. Timed rows (3-digit seconds value) run ~320pt.
- Result: ~314pt ≤ 319pt on 375pt screens (timed rows are borderline within estimate tolerance); ~337pt available on 393pt screens (~23pt slack). The old row was ~690px.
- If a real device still shows crowding/clipping, the fallback is a DELIBERATE two-line-per-set layout in the contract's aesthetic (primary values line, then annotations) — never flexWrap.

Purpose: satisfy Success Criterion 3 (log a set fast, RPE persistent and never behind a modal) with a clean single-line row per the contract's stepper pattern.
Output: SetRow renders as one horizontal stepper line with intentional annotation rows beneath it; edges align inside the card; on-device UAT Test 9 passes against DESIGN-SYSTEM.md.
</objective>
