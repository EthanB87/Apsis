<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HealthKit samples → app logic | External (possibly third-party-written) numeric values enter the engine/DB |
| iOS authorization sheet → app | Scoped read/write identifier request |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-02 | Tampering | sanitizeHKNumeric / mapping | medium | mitigate | Clamp-and-warn every HK numeric (negative distance, NaN duration) before it reaches SQLite or the engine (V5) |
| T-05-03 | Elevation of Privilege | healthkitAuth identifier sets | low | mitigate | Request only workouts/HR/bodyweight read + workout-only write; no bodyweight write (D-18) |
| T-05-01 | Information Disclosure | auth/syncState logging | medium | mitigate | Log only Error objects/booleans/counts — never raw bodyweight or HR values (feeds Phase 06 REL-03) |
</threat_model>
