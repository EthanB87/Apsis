    Extend packages/db/src/schema.ts in place, following the existing conventions exactly.
    Add five new sqliteTable exports:
    (1) `food` — `id: text primaryKey`, `name: text notNull`, `brand: text` (nullable),
        `barcode: text` (nullable), `source: text enum ['user','off','usda','apsis','commercial'] notNull`,
        per-100g reals `kcalPer100g`, `proteinGPer100g`, `carbGPer100g`, `fatGPer100g` (notNull),
        `fiberGPer100g: real` and `sodiumMgPer100g: real` (nullable), `servingName: text` and
        `servingGrams: real` (nullable), `verified: integer boolean default false`, and a
        `createdAt` timestamp default `(unixepoch())`. Add a named index on `barcode` for the
        barcode lookup path. NOTE: the `'apsis'` source enum value is intentionally present but
        unused in v1 (no backend; shared-DB contribution deferred per CONTEXT.md).
    (2) `foodLog` — `id: text primaryKey`, `localDate: text notNull`, `meal: text enum
        ['breakfast','lunch','dinner','snack'] notNull`, `foodId: text` nullable references
        `food.id` (no cascade — a quick-add row has no food), `qtyGrams: real notNull`,
        denormalized `kcal`,`p`,`c`,`f` reals notNull (frozen at log time), `quickAdd: integer
        boolean default false`, `createdAt` timestamp. Add a named index on `localDate`.
    (3) `recipe` — `id: text primaryKey`, `name: text notNull`, `servings: real notNull default 1`,
        `createdAt` timestamp.
    (4) `recipeIngredient` — `id: text primaryKey`, `recipeId: text notNull references recipe.id
        { onDelete: 'cascade' }`, `foodId: text notNull references food.id` (no cascade, mirrors
        strengthSet.exerciseId), `qtyGrams: real notNull`.
    (5) `nutritionTarget` — `id: text primaryKey` (NOT localDate PK — an override may coexist),
        `localDate: text notNull`, `dayType: text enum
        ['heavy_lift','long_run','double','rest','mixed'] notNull`, `kcal`,`proteinG`,`carbG`,
        `fatG` reals notNull, `source: text enum ['auto','override'] notNull default 'auto'`,
        `updatedAt` timestamp. Add a named index on `localDate`.
    Then extend the existing `userProfile` table (in place) with three nullable columns following
    the inline-doc-comment convention already used for healthkitConnected/bodyweightSetAt:
    `heightCm: real('height_cm')`, `birthYear: integer('birth_year')`,
    `goalMode: text('goal_mode', { enum: ['cut','maintain','bulk'] })`.
    Do NOT add any per-user owner/foreign-key column to any new table (no existing table has one;
    Pitfall 4). Update the module doc comment from "six-table schema" to reflect the new tables.
  </action>
