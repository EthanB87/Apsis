## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-15 | Denial of Service (self-inflicted) | hung OFF/USDA fetch | high | mitigate | AbortController timeout (5-8s) on every fetch; local-first search never blocks on network; manual escape hatch always available |
| T-07-16 | Tampering / data integrity | crowdsourced OFF/USDA fields | high | mitigate | Defensive parse (every field optional, both USDA shapes); status:0/missing macros → manual completion, never a silent zero-macro food (Pitfalls 7/8) |
| T-07-17 | Information disclosure | barcode/macro in crash reports | high | mitigate | No barcode/kcal/macro attached to Sentry extra/breadcrumbs; sentrySanitize allowlist enforced (NUTR-22) |
| T-07-18 | Tampering (SQL injection) | barcode/search text → food query | high | mitigate | Parameterized barcode/search builders only (07-03 lineage); no interpolated sql |
| T-07-19 | Repudiation | OFF license compliance | medium | mitigate | ODbL/CC-BY-SA attribution in Settings + descriptive User-Agent per OFF policy (NUTR-21) |
</threat_model>
