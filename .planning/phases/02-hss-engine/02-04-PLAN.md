<objective>
Compose the two per-session primitives into a session score and roll sessions up into a
per-day HSS with the double-session penalty (ENG-03). Session results are version-stamped
(D-06) so stored scores remain re-computable after future constant re-fits, and expose the
raw components (D-05) so constants can be re-fit later.

Purpose: The per-day HSS with double-session penalty is the value Phase 4's home screen and
history view display and label; it is also the input series to the trend engine.
Output: `packages/engine/src/session.ts` (`sessionHSS`, `sessionHSSDetailed`),
`packages/engine/src/daily.ts` (`dailyHSS`), and their test suites.
</objective>
