  <behavior>
    - Warmup exclusion: a set with isWarmup:true contributes 0 to the session score; only working sets count.
    - Per-set stress: setStress = (loadKg / e1rmKg) * reps * (rpe/10); lower-body sets (isLowerBody:true) are multiplied by legMultiplier (default 1.3).
    - Session strength: SS = sum(perSetStress) * kStrength (default kStrength 2.0).
    - RPE clamp: an rpe of 12 is clamped to 10 with a warning; rpe 0 clamped to 1 with a warning.
    - Skip rule: a set with e1rmKg <= 0 is skipped entirely (would divide by zero) and a warning is recorded; it does not crash.
    - estimateE1RM(100, 5) returns 100*(1+5/30) ≈ 116.667.
    - Empty sets array returns 0 (no warnings required).
    - No input ever throws.
  </behavior>

    responsibility ("Strength-side HSS: e1RM-normalized load stress + Epley estimator").
    Import types StrengthSet, EngineConfig, StrengthStressDetail from '@apsis/shared';
    import DEFAULT_CONFIG and mergeConfig from './config'; import clampRange from './clamp'.

    Export `estimateE1RM(loadKg: number, reps: number): number` = loadKg * (1 + reps/30) (D-10).

    Export `strengthStressDetailed(sets: StrengthSet[], cfg?: Partial<EngineConfig>): StrengthStressDetail`:
    merge cfg over DEFAULT_CONFIG via mergeConfig. For each set: skip if isWarmup; clamp rpe into

    compute setStress = (loadKg / e1rmKg) * reps * (rpe/10); if isLowerBody multiply by legMultiplier.
    Collect each computed setStress into perSetStress[]. SS = sum(perSetStress) * kStrength. Return
    { ss, perSetStress, warnings }.

    Export the bare-number facade `strengthStress(sets: StrengthSet[], cfg?: Partial<EngineConfig>): number`
    that returns `strengthStressDetailed(sets, cfg).ss`. Never throw on any input.
