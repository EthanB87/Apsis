    - After a long steady load followed by a zero-load rest week, ATL drops more than CTL over that week (ATL time constant 7 < CTL 28), so TSB = CTL - ATL becomes positive.
    - tsb always equals ctl - atl exactly.
    - computeLoadTrendSeries returns one LoadTrendPoint per input day, in order; the final point's atl/ctl/tsb equals computeLoadTrend on the full array.
    - readinessBand(tsb, ctl, {historyDays:5}) returns 'calibrating' (history < 14).
    - readinessBand(0, 5, {historyDays:30}) returns 'calibrating' (ctl 5 < floor 10).
    - With historyDays >= 14 and ctl >= 10: ratio = tsb/ctl; ratio < -0.30 → 'red'; -0.30 <= ratio < -0.10 → 'amber'; ratio >= -0.10 → 'green'.
    - Cold-start guarantee: for any single-session input (historyDays 1, small ctl), the band is 'calibrating', never 'red' (ENG-06).
  </behavior>
