    - ifFromHR(160, 160) = 1.0; ifFromHR(140, 160) = 0.875.
    - ifFromPace(paceSecPerKm=300, thresholdPaceSecPerKm=300) = 1.0; a faster pace (240 sec/km vs 300 threshold) yields IF > 1.0 (thresholdPace/pace = 1.25).
    - resolveIF prefers HR: given both avgHR/thresholdHR and pace/thresholdPace, it returns the HR-derived IF (D-11); given only pace, it returns the pace-derived IF; given neither, it falls back to a neutral IF (1.0) with a warning.
    - An intensityFactor of 2.0 is clamped to ~1.3 with a warning; never throws.
    - durationS of 0 yields 0 ES.
  </behavior>
  <action>
    Create packages/engine/src/endurance.ts with a module JSDoc header ("Endurance-side HSS:
    duration * IF^2 stress + IF-derivation helpers"). Import EnduranceSegment, EngineConfig,
    EnduranceStressDetail from '@apsis/shared'; DEFAULT_CONFIG, mergeConfig from './config';
    clampRange from './clamp'.

    Export `ifFromHR(avgHR: number, thresholdHR: number): number` = avgHR / thresholdHR.
    Export `ifFromPace(paceSecPerKm: number, thresholdPaceSecPerKm: number): number` =
    thresholdPaceSecPerKm / paceSecPerKm (faster pace → smaller sec/km → higher IF).
    Both guard against a zero/negative denominator (return a neutral 1.0 rather than dividing
    by zero) and are pure.

    Export `resolveIF(inputs: { avgHR?: number; thresholdHR?: number; paceSecPerKm?: number; thresholdPaceSecPerKm?: number }): { intensityFactor: number; warnings: string[] }`.
    Precedence (D-11): if both avgHR and thresholdHR are finite/positive → use ifFromHR; else if
    both pace values are finite/positive → use ifFromPace; else → 1.0 with a warning "IF unresolved,
    defaulted to 1.0". Clamp the resolved IF into the range [0.3, 1.3] via clampRange, appending any
    clamp warning.

    Export `enduranceStressDetailed(seg: EnduranceSegment, cfg?: Partial<EngineConfig>): EnduranceStressDetail`:
    merge cfg over DEFAULT_CONFIG; clamp seg.intensityFactor into [0.3, 1.3] and seg.durationS into
    [0, +inf) via clampRange collecting warnings; durationMin = clampedDurationS / 60;
    es = durationMin * intensityFactor^2 * kEndurance. Return { es, warnings }.

    Export the bare-number facade `enduranceStress(seg: EnduranceSegment, cfg?: Partial<EngineConfig>): number`
    = enduranceStressDetailed(seg, cfg).es. Never throw.
